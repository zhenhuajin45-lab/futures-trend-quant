# 100 万账户品种矩阵状态

`sizing_table.csv` 当前是明确的缺证据清单，不是估算结果。仓库中尚无 2023 年起的十品种连续 M1/日线数据，也没有模拟盘实际手续费表；因此价格、ATR、日均成交量和所有手数列保持为空，`status=EVIDENCE_MISSING`。这里不使用截图报价、四天回测样本或网上费率填空，避免把不可复核数字伪装成品种结论。

可执行计算在 `backtest/sizing_table.py`：

- 主账户：100 万元；敏感性：50 万元、200 万元；
- 单笔风险上限：1%；
- 止损距离：1.5 / 3 / 6 ATR；
- 单笔流动性上限：日均成交量的 0.1%；
- 手数取风险手数与流动性手数的较小值；
- 每手风险包含 `ATR × 止损倍数 × 合约乘数` 与已核验往返成本。

要把表转为可用于品种去留的结果，需先执行 `futures_trend_quant/data/gm_export.py` 导出完整历史并填入经模拟盘账户核验的 `config/fees.json`。任何字段仍为空或 `verified=false` 时，离线 runner 会 fail-closed，不生成收益报告。
