**二、本轮选择路径：先核数据，再定一条机制**

首批最多整理两张有一手依据的候选卡，按字段可得性、信号时钟、兑现期限、成本压力和对照可构造性选一张。不同时跑两个候选收益，也不因一个失败自动启动另一个。

| 候选资料方向 | 首批核查的具体内容 | 可以与不可以得出的结论 |
|---|---|---|
| `M1_SESSION_RELATION`：起始小节与尾段短窗口的关系 | 参考首半小时与尾半小时研究，核查同实际合约 M1、交易日归属、夜盘起点、末段小节及事前止损锚。明确原文中的日盘／夜盘定义与本项目的差异 | 数据要求较低，适合先核现有库存。论文的 30 分钟只能作为一个有出处的研究定义，不能当成已证实的本项目最佳窗口。若收市前清仓纪律要求改为提前退出，该适配须单列为新假设 |
| `OBI5_FEASIBILITY_ONLY`：盘口失衡 | 核查连续五档价量、接收时刻、报价更新、交易小节、时钟精度及适用费用。记录作者的原始定义和主动成交负结果 | 有五档及接收时间才有条件核对应信号。预测力尚不足以支持赚钱；必须解释本项目相对于作者负结果有什么可检验的差异，不能仅换品种或参数再试 |

这是数据和文献的预检清单，尚未选定新策略。现有资料支持优先核查 M1 可表达的机制；如果本机确有完整盘口原件，可以按同一标准比较。**不把短半衰期当成更容易赚钱的理由：它往往对延迟和点差更敏感。**

选题顺序固定为：先列字段与出处 → 核原件是否存在 → 写出完整触发及风险锚 → 指定实际兑现窗口和主对照 → 核触发容量 → 冻结唯一开发假设。无法完成任一步时，首批照实交付缺项或停止。禁止按收益选窗口或品种。

对于早期失效，要求明确“看到什么就执行什么”，并承认提前退出会错过随后获利的交易。若没有独立依据支持某个早退条件，不人为增加“5 分钟不涨就退出”等规则。可以预先选择仅以固定窗口到期、结构止损及目标作为失效／退出口径，但须标明“没有提前预测失败的证据”。有限持仓本身可检验，提前识别失败是另一项待证假设。

静态挂单量失衡与主动成交订单流分别定义。M1 涨跌和成交量不能补造缺失的主动买卖方向。只有 L1 时只能登记另一条 L1 假设及来源，不能称为复现五档研究，不能在五档缺失后自动改跑 L1 收益。

**四、无收益预检的输入与算法合同**

机制单必须有以下字段。尚无证据的栏填 `UNVERIFIED`，不得由 AI 编造团队经验。

| 字段 | 填写要求 |
|---|---|
| 可观察触发 | 输入字段、实物来源、合法合约、触发算法、历史窗口和数据首次可用时点 |
| 预期兑现窗口 | 入场后 H 个可交易分钟、允许的小节、自然时间最大长度、规则清仓启动及最迟归零时刻 |
| 失效／退出 | 确切观察事实、最晚判定时刻和下一合法退出方式；无早退依据时明确只采用窗口到期及风险退出。早退规则有误杀代价 |
| 2R 可达性假设 | 止损锚和 R0、目标构造、未来应统计哪些先达与超时结果。预检阶段不填真实条件频率 |
| 支持与失败案例 | 使用已公开研究或已有记录中的带时间例子，附数据。案例验证只支持判据可解释；随机案例单独留存。参与者已见结果时如实记自检 |
| 同期成本和延迟 | 收费依据、价差、可见深度、时钟精度、处理延迟和委托传输延迟各自已知／未知 |
| 主对照及主结论 | 究竟检验方向、触发还是早退，只设一个主比较。方向机制可采用事前固定的同品种、同时段安慰剂方向对照；触发机制可采用同状态匹配普通时刻；早退机制用完全相同入场但无早退的对照。必须选定并冻结其算法，不能三者跑完择优。范围写明单品种、小池或跨品种 |
| 数据边界 | 机制设计资料、开发窗、一次独立窗、预热及标签尾段，逐一列重叠检查和历史访问记录 |

预检程序只读取事件形成以前需要的字段，并输出计数和质量。P&L、未来收益、最大有利／不利运动、目标／止损首触、以及收益排序均留给后续开发。计算“同类事件过去到达 2R 的频率”本身已经是结果研究，须在开发登记后进行。

统一时钟语义为 `event_at`、`received_at`、`signal_ready_at`、`order_eligible_at`、`fill_model_at`。历史数据只有事件时间时标 `EVENT_TIME_PROXY`，仍可做限定的描述和工程检查，无法证明严格接收顺序。信号使用的任一字段时间晚于 `signal_ready_at`，事件判无效。进入时刻取信号可用、规定进入窗口及假设总延迟之后的下一合法报价／bar，禁止使用信号形成同价瞬间成交。

缺接收时钟不全盘抹掉 M1 资料的描述用途，但必须阻止微结构的成交时延结论。报价陈旧阈值在看结果前根据数据频率、实际只读处理性能和策略期限冻结。只读脚本能测计算时延；柜台传输和撮合时延仍需单独依据。未经同步校准的交易所与本机时钟差不可直接当作传输时延。

候选容量以原始行情上的全部有效机会为母样本。原 631 笔成交账本不承载新策略的机会集合。连续触发按预登记 H 分钟冷却或事件结束规则合并，不用反复一分钟触发虚增样本。数据缺失、缺少报价和无成交仍计入机会总数及各自分母。

**五、容量标准改为“能检测多大的效果”**

初期预检报告原始触发数、独立时间块、参与品种与相关组，避免强制九格。主要分层仅为方案事先需要的交易小节与品种。所有声明限定于原先固定的样本范围。

在没有收益标签的阶段，用计数给出可检测效应的区间估计，不宣称精确功效。项目负责人先登记最低值得投入的净增量 `delta_min`，以每笔初始风险 R 或每个交易日风险单位度量，并写出资源理由。若暂缺可靠方差，使用保守方差范围并报敏感性，不挑有利数值。

例如独立、近似正态的配对差值，双侧 5% 显著性、80% 功效时，可用 `n ≈ 7.85 × sigma_delta² / delta_min²` 作粗略预算。若 sigma_delta=1R、delta_min=0.1R，约需 785 个独立配对。这只是容量算例。真实交易自相关、厚尾和同期品种关联会改变需求，分钟数不能代替独立配对数。

进入开发后，可用开发窗估计方差和交易日聚类程度，在独立窗开盲前完成整日区块抽样／效应注入功效评估，冻结独立长度与主指标。独立结果不足时记证据不足，不能读完再延窗。单品种可以研究，但“跨品种稳定”需要预定多品种设计及相应功效，不能靠数量凑够。

第一批决定按以下表自动生成。

| 决定 | 条件 | 下一步 |
|---|---|---|
| `STOP_NO_MECHANISM` | 无法给出触发、窗口、失效／退出、风险锚或可构造对照；可解释案例缺失且没有足够的一手机制依据 | 结束孵化，保留缺项 |
| `NEED_DATA_DECISION` | 机制可定义，但所需字段、完整窗、时钟或报价无可核原件 | 输出最小数据规格、可用来源、授权与交期。计数等已能做的工作完成后结束本批 |
| `NOT_TESTABLE_WITHIN_SCOPE` | 在已授权数据和固定研究范围内，容量／时段／风险锚不足，或窗口无法兼容短持限制 | 结束候选，不能按收益挑小池重新命名 |
| `READY_FOR_DEVELOPMENT_DESIGN` | 单一机制可复现、字段及范围合格、容量估计和成本／延迟取证路径明确，对照已冻结 | 形成一个开发协议。可做毛机制开发时与可签净经济性时分开；缺费用不阻断毛响应研究，但不能签净收益。协议及相应层级数据合格后才运行 |

**六、开发验证先检查信号是否存活到成交，再做账户**

开发窗和独立窗须避开已经使用和被保护的集合。登记边界包括 V9/V10 的 2025-09-01 至 12-31、V7.1 的 2026-01-05 至 04-24 及截至 05-06 的标签尾段、V6–V11 的 2026-05-07 至 11-02 研究窗，以及从 2026-11-04 21:00 起的正式 90 交易日协议。具体交易日和保护终点以原文件为准，禁止凭日期空隙认为独立。旧窗仅用于已标明的工程、字段和容量预检，读过的价格也不能再宣称从未见过。需要动用已保护数据必须先有明确的解除决定。

开发分两步，用同一冻结候选，步骤之间不选参数。

第一步做事件响应。完整输出信号价参考变化、下一可执行对手价变化、达到主窗口 H 的变化，以及 1/5/15/30/60 个交易分钟的预登记描述曲线。主 H 由机制先确定，附属曲线不能用来挑一个新持有期。候选和主对照按各自预登记的事件匹配规则核对，所有未来标签存入隔离输出，不能回写触发特征。

长仓的可执行价格差以 `bid_exit − ask_entry` 为基础，短仓以 `bid_entry − ask_exit` 为基础，点差已在其中，避免再次扣同一项。分别保留入场前就实现的价格移动、入场后移动、模型成本、不可支持成交量和未平敞口。若信号时参考收益较好、下一可成交时刻之后优势消失，记 `STOP_EXECUTION_DECAY`。不会因这个结果自动改用挂单模型。

真实费率未知时只报毛价格变化、tick／R 尺度和可承受成本上界，净收益栏为空。实际费用按合约、日期、开／平今／平昨、加收和舍入规则计算。数据准入与经济通过分别记录，参考费率不签经济性。

第二步才用两个完整账户检验候选与已冻结的主对照。除正在检验的单一差异外，两组共用初始资金、合法交易小节、结构止损口径、2R 目标、组合限额与硬清仓规则，各自顺序处理资金、手数、成交及再入场。若采用安慰剂方向，种子、重复次数及对照汇总规则必须事先固定，不能挑某次路径作比较。复用仓库已核对的账户逻辑，清楚拆出旧 S0 方向／入场依赖，防止不经登记又把旧逻辑嵌回。事件表筛选出的均值不能代替账户重放。

每个事件的净期望应按实际结局计算。理想 +2R／−1R 情况可写为
`E[R_net] = 2·p_target − p_stop + Σ(p_other × mean_R_other) − E[cost_R]`。
真实止损跳空、部分成交和早退则使用实际模型 R 替换理想常数。报告目标、止损、早退、时间退出、双触未知、缺行情／未平各自分母。早退减少的亏损与错过的后续盈利同时保留。

开发通过需要候选自身费后期望为正、主比较有超过登记最低增量的依据、合理延迟／成本压力下有余量、容量与亏损集中可解释。若候选没有增量而对照盈利，登记为主假设未获支持。更换最终策略须形成新版本和独立协议，不当场转正对照。
