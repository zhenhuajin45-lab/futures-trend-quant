# V11 执行任务书｜从一次旧窗二维诊断到模拟盘观察

**交给本机 Codex 和非答题复核人。现在执行任务 1–3。任务 4–6 只在各自前置条件满足后执行。**

本项目做国内期货短线波段。要验证的是：在同一方向授权、结构止损、2R 目标和 D+1／休市前清仓纪律下，开仓前放弃一部分简单入场，能否让完整账户在可核验成本下赚得更多，并把最大 M1 收盘回撤控制在 15% 以内。最终交付是一个有资格接受模拟撮合观察的冻结版本，或一份说明在哪一步应停的真实结果。

## 任务 2｜原件只跑一次，把空间、品种和路径分开看

**先手算两例，再全量。** 用与盈亏无关的稳定交易 ID 顺序，按预登记条件取首个跨夜／跨午休案例和首个涉及换月边界的案例。没有该类时记缺。复核人看截点前价格、小节、映射、单位、20 个参考段及止损，独立复算可交易分钟和空间比，再与程序对比。缺一段时核对未知原因也算有效的工程检查。若两例均无法检验有数值的价格分支，按预登记顺序追加首个仅凭输入完整性可算的案例，只做算术核对。校验差异先停，不能用收益挑例。

**特征时钟。** 在信号已闭合时，按当时已知的日历定位下一合法入场时刻，与账本模型入场时刻交叉核对。从该时刻到最早强制清仓启动，按实际合约逐小节计交易分钟，扣休市。20 段必须同实际合约、同一北京时间起点、相同可交易块长度序列，在信号形成前或当时已结束。选最近 20 段后才检查完整性，缺分钟不向前递补。R0 取信号收盘价与当时有效结构止损的方向有效距离，统一价格单位。模型成交价只进入成交和事后路径。旧缓存的行情事件时钟只作历史代理。

## 任务 3｜由程序裁决，锁死一次修复的边界

以下比较都用未四舍五入的值。零归非正。先判资料是否足以回答问题，后判混杂和机制。**未通过、不可判定、品种混杂是三个不同的研究结论。**

| 判定顺序 | 触发条件与动作 |
|---|---|
| ① `INDETERMINATE`（不可判定） | 原件、回执或时钟缺失；双维未知比例超过全部 631 笔的 20%；三分位高、低空间组任一端少于 100 笔；九格中任一格少于 20 笔；三分位、中位数或固定 2R 比较中共同品种少于 5 个；任一比较用于裁决的高／低两侧中，缺数＋双触合计占该侧超过 20%，或需要的统计量未定义。稀疏不是负证据。只准一次有明确原件或可复现读取错误的修复 |
| ② `STOP_PRODUCT_MIX`（品种构成或集中风险） | 三分位全池高减低为正、同品种同时间等权差却 ≤0，记“方向反转”；或合格两端中任一端最大品种笔数占比 >50%，记“过度集中”；或同品种等权原为正，剔除两端合计笔数最多的品种后变为非正，记“依赖单一品种”。并列最大逐一剔除，只要一项触发即记录。固定原切点、不重新分组。报告可观察到的构成变化，不断言因果。停止投入 |
| ③ `STOP_MECHANISM`（有数据但未支持） | 资料充足且无上述混杂触发，以下通过条件中有一项不满足即停，并列出失败项。如只有平均值改善而中位数、截尾均值不改善，记录“分布不稳”；高波幅伴随更高的止损先达比例，记录“路径不符”。不调参数、不另选品种 |
| ④ `READY_FOR_BLIND_REVIEW`（有旧窗线索） | 三分位、2×2 同品种等权平均毛 R 差均 >0；三分位至少 2/3 合格品种差值 >0；三分位等权中位数差、截尾均值差均 >0。路径要求三分位等权目标先达差 ≥0、止损先达差 ≤0，且至少一项严格改善。固定 2R 的同品种等权平均毛 R 差也须 >0，且首触两指标无反向。输出只准进入双人盲判准备 |

覆盖规则也要可复算。100 笔按共同样本的高、低两组分别累计，跨时间层合计，不取九格对角。50% 集中度在三分位匹配成功的交易中按高、低两侧分别统计。20% 的路径上限也在各比较实际纳入的交易中逐侧计算；来源缺失和双触歧义分别列数，二者合计只用于评估能否识别首触。同品种等权路径差仅使用两侧都有可排序路径的层，若某个纳入层一侧无可排序路径，标不可判定，不事后删除该层。

容量门槛是探索性投入标准。程序先保留所有失败标志，再按表中优先级出唯一主状态。原件或回执未到时可记子码 `BLOCKED_INPUTS`／`AWAITING_SIGNOFF`；尚未跑数不计运行次数。修复只能纠正同一批可信字节的定位、解析或已举证的计算缺陷，不得换源、补选第 21 段、改门槛或删样本。新旧代码、原因、结果并存并由原复核人复签。若仅因策略交易少而达不到容量，修数据无济于事，直接记录“不可判定，低优先级归档”。原件修后一轮仍不足同样归档。原 HOLD 时间不重置，按既定的首次书面交付日 +14 天及采纳日 +60 天较早者执行，未登记首个交付日仅适用外层截止。

**给 Codex 的汇总入口接口。** 实现 `python -m tools.v11_diagnostic.summarize --input <原诊断目录> --prereg <冻结登记.json> --receipts <回执目录> --out <全新汇总目录>`。以临时目录生成整套输出，验证文件齐全并生成摘要后一次发布。正式运行须绑定原件双摘要、源队列和对应 `audit.csv`，拒绝草案或合成账本进入正式目录。合成目录独立，标 `SYNTHETIC_ONLY`。测试至少断言以下整套输出的主状态。

| 合成反例（其余条件均满足） | 预期裁决 |
|---|---|
| 缺数 21%，全池看似提升 | 不可判定，禁止输出候选通过 |
| 全池差 +0.10R，同品种同时间差 −0.02R | 品种混杂停止 |
| 同品种差为正，目标先达率上升但止损先达率也上升 | 机制未获支持，原因“路径不符” |
| 三分位和 2×2 均通过，实际 ≥2 对 <2 的同品种差为零 | 机制未获支持，原因“实际门槛无区分” |
| 两端和九格达容量线，均值、分布、品种、首触及固定 2R 全部通过 | 仅准准备盲判 |

**封存先于盲抽。** 执行人将明细、汇总、裁决及摘要写入全新目录，复核人比对指纹并封存。两位答题人交卷前不看汇总、原账本或本次诊断明细。已看过抽样候选库逐笔未来结果者不得充当该库的盲判人，必要时换人。通过后由非答题人先封存日志索引、纳排规则、随机种子、算法和版本，再抽至少一个事前未知案例，不重抽。正、反例需有当时带时间戳的实物。两人独立写判断，主持人提供实际合约、小节日历、信号与强退时间锚；仅用信号时已收到的数据，缺项记 `NOT_AVAILABLE_AT_SIGNAL`。无法独立复述、无有效原件或判据不一致，V11 留档。盲判通过只证明可复述。

- 开发窗首要比较为候选减简单入场的平均每笔毛 R。按相同交易日同步抽取 5/10 日连续块、每种 10,000 次、种子 20261104，保留零交易日。**建议开发通过线**为两种差值 95% 区间下界均 >0，完整账户毛损益增量为正，剔除头号贡献品种后不变号，成本主档可算且候选净损益为正。若仅提高胜率、区间跨零、容量不足或收益集中，停止投入并保全独立窗。各项都登记后才开跑。

## 任务 5｜一次独立回测，决定有无资格看模拟撮合

在读开发或独立收益前，登记下表的数值、价格参考点、作废条件和唯一候选。独立窗触发前先完成无收益预检，封住输入、代码、参数和评估器指纹。开盲时原子登记唯一运行 ID；故障只按同一指纹恢复同一次运行，不允许另挑窗口、增加样本天数或从对照组临时挑赢家。下列容量与统计门槛是 **V11 建议值**，15% 是项目已冻结的风险预算。有效交易日、样本范围和利润单位须写进登记文件。

| 关口 | 建议晋级标准 |
|---|---|
| 样本容量和成本 | 至少 60 个完整评分交易日、每个账户至少 100 笔已平。每笔开、平及期末未平已付成本可追溯。表 B 区分真实回报与模型成交，回测始终报告模型净值。按各次成交价×乘数×手数算金额项，固定元/手项另计。缺任一关键费率、报价或退出成本覆盖，结论为 `INSUFFICIENT_EVIDENCE` |
| 盘口与可执行压力 | 可见深度 100% 作乐观档、50% 作主判档、0% 作无法依赖当前盘口的敞口情景。按可见各档整手向下取整，每份报价数量只分配一次，超出可见量保留未成交或部分成交。另在同一 50% 可支持的模型成交上做预注册每边额外 1 tick 的损益压力，重放资金与手数，区分已计点差和附加冲击。它不增加可成交量。0% 档只报未平风险和容量，净 R 不可估即留空 |
| 经济性与增量 | 主判档和上述有成交的压力档，候选平均每笔模型净 R、含未平估值的期末模型净损益均 >0，两档最大 M1 收盘回撤均 ≤15%。主判档下，候选自身平均净 R、候选相对对照平均净 R 的同步 5/10 日块 95% 区间下界均 >0，且候选期末含估值净损益高于对照。主判和压力分别核对剔除头号盈利品种、剔除最大五笔盈利交易后的已平净损益仍为正。这是账本集中度检查。窗口中有未能计价的敞口，标未知，不给经济性通过 |
| 短持纪律与安全 | 100% 应平事件有记录，按实际合约、方向、适用今昨和投保属性核对。截止前未归零或仓位未知均阻止进入模拟；分母保留，分别标出规则无交易时间、延迟发令、无报价、柜台／模型状态未对平。回放归零是模型证据，模拟阶段再检实际回报。0% 极端假设不冒充实际违约，但须披露敞口 |

任何经济门槛未过，记录失败项；数据、容量或成本不足则明确记录证据不足。两者均不启动模拟。不能用参考费率、单笔最高盈利、胜率、或一段旧窗赚钱替代以上条件。

## 任务 6｜模拟观察的启动、暂停和交付

**独立通过只能申请模拟观察。** 工程负责人先在隔离的模拟适配器上通过断言和回放测试，项目负责人核对账户白名单、环境、最大手数、订阅覆盖与应急联系人后单独授权。现有 GM `_can_place_orders` 是回测闸门，禁止通过修改 `execute_enabled` 绕过。此任务书本身不授权下单。

- 工程验收覆盖启动恢复已有持仓和活动单、零成交拒撤、部分成交后撤单、重复和乱序回报、未知状态、断线重连、晚到持仓快照、报价陈旧。持仓侧按委托终态与成交回报对齐后的有效快照核实**实际余额**。冻结量、可平量只作对账。撤单后可平恢复 1 手且实际余仓 1 手，必须判未平。非预期投保属性记 `UNEXPECTED_HEDGE`，账单时序不一致记 `PENDING_RECON`；汇总不得签零。分别记录规则启动至截止的 `window_rule` 和实际发令至截止的 `window_order`。
- 模拟只观察胜出版本。建议事先登记首个 20 个完整交易日及至少 30 笔已平作为**运行质量观察量**，逐日对同版只读影子账和模拟柜台账。逐笔记录信号、意图、委托、回报、成交、手续费、部分/未成交；按方向与手数对比滑点，逐次复核所有纪律清仓。差异须能归到时间、价格、数量、资金或状态字段。
- 账户环境异常、重复开仓、未知敞口、纪律截止仍有余仓或触及 15% 回撤预算，立即阻断新增、保留受控退出与对账并通知人工。批准观察窗结束后给 `观察完成`／`容量不足`／`执行差异需修复`。此次交付到模拟观察报告为止。

## 给本机 Codex 的启动指令

> 在隔离研究工作区执行本书任务 1–3。先检查原件路径和 SHA-256，不读取其盈亏；编写并测试只读统计与自动裁决入口，生成待签预注册包。无需重跑 V10 或既有验收。双人回执及手算核对齐备后，只运行一次完整旧窗二维诊断，封存结果并报告状态。缺真实原件或真实签署时，先交付已通过合成验收的命令、代码、测试和准确缺项，禁止模拟签字或伪造九格。无论结果如何，报告四件事：处理了多少笔、同品种证据如何、路径是否支持、由谁做下一步。仅在各关通过且授权齐备后执行后续任务。保持模拟和实盘订单关闭，不修改 main，不公开行情原件或逐笔盲判材料。

**交付节奏。** 从本机执行人接手计，建议第一个工作日交付可运行的统计入口、合成用例和待签摘要；若原件和双签齐备，下一个工作日完成手算、全量补算和封存。原件未到只登记到件条件，数据等待不计入执行工时。后续开发窗和独立窗只按数据到件和关口释放，不承诺日历上的模拟盘启动日。

**第一批交付的完成标志。** 具备原件时，交付双签摘要、两例手算、两张分层表、同品种及固定 2R 表、路径与容量表、单一机器裁决、重放命令和受限明细摘要。不具备原件时，交付同一入口及其合成失败用例、具体缺哪份原件或回执和一次修复边界。项目负责人据裁决分配下一笔研究预算。
