## 唯一筛选器的工程交付

研究层 `tools/first_entry_v7/selector.py` 接收闭合 M15 的 S0 核心输出，`frame_from_v6` 按原 `build_stop_plan` 在信号收盘验证结构止损，再进入 `FirstValidOnly.step`。输入白名单不含下一开盘、未来完整性或首触标签。

| 字段或边界 | 已冻结行为 |
|---|---|
| `episode_id` | `csymbol|actual_contract|direction|observed_start_eob`；左删失另有标识 |
| `slot` | 第一份合法、未用证据在收盘时消耗；只记录机会键 |
| 后续开盘无效、缺数、删失 | 保留已消耗名额，不递补 |
| 同证据跨 bar | `DUPLICATE_EVIDENCE`；与 V6 原证据键一致 |
| none 后重入、直接翻向 | 开始新段；普通休市和跨零点不重置 |
| 换月与旧腿重新被选中 | 按实际合约保留状态；不继承另一腿名额，也不清空旧腿名额 |
| 样本起点已在段内、缺失前缀 | `LEFT_CENSORED_FIRST_UNKNOWN`，不能冒充真正首次 |
| 有可核预历史 | 预样本第一份证据 `PRE_SAMPLE_CONSUMED`，评分窗不重新给名额 |
| 段末尚未观察到 | `end_known=false`，不混入完整有效段分母 |

`run_selector.py` 先执行独立样本准入，再核验原价、回放、日历、schedule、selection 哈希，使用实际 M1 完整桶核查向过去至少 1,200 根 M15。它只生成选择结果，不评分。源回放可能不输出最早的指标预热柱，因此不能拿“已输出回放行数”替代实际完整预热数量。本轮自审已用原始 M1 时钟计数，并加入缺分钟/重复分钟测试。

新段 ID 同时附对应回放按 V6 `state != last_state` 累加的 `v6_episode`。两者不强行等价：未知段首、中断和换腿边界必须单列，不能借 V6 数字段号掩盖左删失。旧窗只复核容量上界：284/3,787=7.50%；1,097 个目标事件分布在 138 段，每段一次即使事后任选也最多 138/1,097=12.58%，至少移除 959 次目标事件。**未在旧窗运行首次筛选器，这些不是候选真实成绩。**

### 新样本开算前固定的裁决

目标是每段争取一次有效入场。候选相对全 S0 的结构风险主比较须至少 +2 个百分点，5 日块下限 >0，10 日方向一致；完整有效趋势段至少保留 50%。有效段要求可确定段首、段末及相关机会，分母为 S0 至少一次明确 TARGET_FIRST 的段，分子为首次也明确成功的段。预历史已消耗、左删失、开放末段和机会资料不完整各列数量及上下界。

普通对照在全体 S0 上一次匹配，再按候选键取子集；双方主要采用各自闭合 ATR×1.5 的对称尺度，结构风险结果另列，不能混同两个目标。仅当匹配覆盖≥70%、候选相对普通时刻的 5 日块下限 >0，才声称超过普通时刻。未配对、开盘无效、双触、跨段和删失单列。候选/基线是嵌套子集，块重采样须共同重算两组比例，不能直接套独立比例误差。

合理删失边界会改变门槛结论时判证据不足；容量或质量明确失败即归档，不在同窗追加变体。普通对照风险的说明已在新样本标签打开前补入登记；没有新增参数或候选。
