## 已核实环境与只读结果

- 本机 GM 数据 Python 3.13 / SDK 3.0.186 未升级。官方仿真 `gmtrade==3.0.6` 使用新增隔离 Python 3.10 环境，固定官方仿真端点。目标在终端模拟账户页面及官方指定账户现金查询中核对一致。账户 ID 和原件私有。
- 指定模拟账户初始净值 1,000,000 元，初始持仓、当日委托、成交及活动单均为 0。全部查询显式账户。
- 当日 GM 实际主用合约 `DCE.m2701`，tick=1，乘数=10，元数据保证金率=0.07。DCE 日历和该合约实际小节用于分钟分母；不使用 SHSE 日历替代。
- 本机只读接入读到 22,000 根 M1，最近 1,200 根完整 M15 所需分钟缺失 0。预热覆盖 2026-08-14 14:16 至 2026-11-05 11:30（北京时间），只重建状态、不计算旧收益。
