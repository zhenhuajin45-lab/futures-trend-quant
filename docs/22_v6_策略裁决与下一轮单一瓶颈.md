# V6 策略裁决：停止提速，优先验证入场筛选

**当前S0技术入场时点没有比同方向、同合约、相近条件下的普通时刻更容易先达到2R。本轮停止M5提速试验，下一轮唯一研究瓶颈是入场筛选的增量价值。** 策略参数保持冻结，模拟盘与实盘下单保持关闭。本文件是历史研究裁决，不构成正式90日样本准入或交易批准。

## 最早有直接证据的问题

优先处理**技术入场选择器**：在方向授权、合约、交易日/小节、动能状态和波动尺度受到控制后，现有触发时点的目标先达比例仍更低。与其增加形态和阈值，先验证这套筛选是否值得保留。

建势能力也有限：370个完整快速参考段中，S0只有171个在最有利收盘之前完成段内两根确认，87个已到/过极值，112个未完成；EMA34相应为258/93/19。134段在参考确认当根已经同向，不能将整个表解释成“S0此时才首次建势”。

另按真实新方向状态转换观察334个合格新授权episode：314个未来48根完整，165个曾提供至少3 ATR顺向幅度；247个共同完整的“授权—首次合法候选”事件，两锚点顺向空间各自中位3.235/3.303 ATR，候选延迟中位2根M15。没有证据据此认定单纯加快评估就能扭转主比较。

结构R/ATR中位1.529，接近冻结的1.5下限。完整机会中289/3,374达到3 ATR却未达到结构2R；608/3,374则先止损、后来才出现2R幅度。问题包含顺序与选择，不能直接归为“止损普遍过宽”。本轮不放宽/收紧止损，不重开离场A/B改造。

## T3停止与下一项最小实验

`T3 = STOPPED_NO_POSITIVE_ENTRY_ENRICHMENT`。本轮没有运行更早M5全部合法前提的反事实回放，因而不声称不存在更早合法信号，也不声称改频率必然无效。停止理由是预登记主比较没有正向富集证据。

下一轮只登记一个可逆的入场选择实验：

- 基线：现有S0全部首次有效独立证据，机会层无持仓/成交假设保持一致。
- 唯一候选：`first_valid_only_per_episode`。每个同品种、实际合约、同方向的连续趋势episode，仅保留第一份原规则已经合法的未使用证据；后续新证据不再产生机会。方向状态、H1、路径A/B/C/D、指标、锚点、止损和评估频率均保持原样。
- 原因假设：同一趋势段的后续触发可能选择了更差的位置。该因果机制尚未证实，本轮**未运行**此变体，也没有用当前窗口挑阈值。
- 下一轮必须在预先固定的新评估样本统一报告：保留/移除机会、原有完整目标事件被丢弃多少、首触比例增量、按交易日块的区间和完整episode容量。只减少机会数或提高比例、却大量丢失有效趋势机会，不能判为通过。成交持仓互斥与冷却另有上下文，不将该机会层过滤当作账户回测。
- 若新样本无正增量或容量不足，结束此过滤方向，不在同一窗口追加多个变体。

这是下一轮单一研究方案，尚未形成策略修改或准入批准。当前有效交付为[完整报告](21_v6_历史趋势与2R机会验证报告.md)、逐机会/参考段明细、11类真实算术案例、补片传导及复算入口。
