## 范围

本轮只验证以下路径：

`掘金策略入口 → 连续合约映射 → 主力真实合约 → 60s/300s/900s 订阅 → 闭合 bar 滑窗 → M15 指标事实`

2. 掘金回调 bar 对象遵循官方示例的 `bar['field']` 下标协议，但不能假设可转换为
   `dict(bar)`。入口已改为下标读取，并加入 GM-like 对象回归用例。
