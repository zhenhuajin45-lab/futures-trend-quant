# 国内期货趋势策略：附件评估与落地基线

> 日期：2026-11-03
> 状态：阅读完成；允许进入 T0-T2，禁止直接启用自动下单
> 数据与交易平台：本机信达掘金终端 / `gm` Python SDK 3.0.186

## 1. 结论

1. 附件定义的不是一套已经验证盈利的期货策略，而是一套待验证的确定性规则假设。现有 XAUUSD 完整回测只有约 4.5 天，4 笔全亏、合计约 -2.22R，趋势方向一致率约 47%；主要污染来自模型生成的背驰事实，但不能据此反推确定性版本有效。
2. L1 结构事实、L2 趋势状态机、L5 组合风控和期货适配规格已足够开始编码。L3/L4 入场、锚点与价位不能只凭文字重写，必须取得原始 `m5m1-combo-v1`、`structure-facts` 和 31 个黄金用例后才能声称 1:1 移植。
3. 第一阶段必须是离线数据、事实算子、状态机与回测台；掘金侧先运行信号模式。`execute_enabled` 默认且持续为 `false`，直到开发集、验证集、模拟盘逐根一致性和执行风控全部通过。
4. 国内期货适配的关键不是把 XAUUSD 美元阈值直接换成价格点，而是改为 ATR、合约乘数、整数手、交易时段、主力换月、涨跌停、平今费用和品种簇约束。

## 3. 策略事实合同

### 3.1 周期与闭合边界

- 订阅周期：M1=`60s`、M5=`300s`、M15=`900s`。
- H1 默认按每个交易时段内 4 根已收盘 M15 聚合；夜盘与日盘分别起组，不用墙钟小时线跨休市拼接。
- 所有事实算子只读已收盘 bar，并输出 `defined_at`；回测与实时共用同一核心代码。
- 冷却和等待使用 bar 根数，不使用自然分钟：2 根 M15 确认、4 根 M15 冷却、60 根 M1 等待等。
- 休市不补空 bar；首根跳空超过 `gap_atr` 时禁止把该根用作反向形态证据。

### 3.2 指标

- EMA34，全周期一致。
- M15 slope：`(EMA34[0] - EMA34[12]) / ATR14`；`>=0.35` 为 up，`<=-0.35` 为 down，其余 flat。
- MACD：EMA12/26，signal EMA9，`hist=DIF-DEA`，不乘 2；至少 251 根已收盘预热。
- 背驰签认数据集有 8 段、1570 条展示 bar、116 个待签认标记；标记来源为 GDL 65、平台 5、模型 C1 12、模型 T1030 34。数据集没有真值标签，不能把来源当作正确答案。

### 3.3 趋势状态机

状态：`none/bull/bear`，持久化字段至少包括：

- `trend_state`
- `since`
- `trend_extreme`
- `blocked_dir`
- `last_divergence`
- `h1_bar_state`
- `leave_votes`
- `establish_votes`
- `last_closed_bar_id`
- `facts_revision`

规则：

- `none` 建立趋势：收盘在 EMA34 同侧、slope 同向、无反向背驰，连续 2 根 M15 同方向才确认。
- 已有趋势默认维持；结束只允许路径一 `N and S and P` 或路径二 `R`。
- 路径一：已确认且仍有效的反向背驰；新极值后 slope 走平或极值附近反向形态；收盘穿 EMA34 或背驰后 MACD 反向交叉。
- 路径二：收盘到 EMA34 反侧、slope 不再原方向、极值附近出现反向吞没或 pinbar+破位；不要求背驰。
- H1 只在 M15 结束路径成立后裁决；同向 strong 否决，weakening 无背驰转 none，weakening 有背驰/flat/reverse 可翻转。
- 离开趋势的提议合并计票，连续 2 根 M15 才确认；目标状态取第 2 根的最新提议。
- H1 strong 下的极强例外只允许路径一且 E1-E4 全满足，结果是转 none 并设置 `blocked_dir`，不是直接反向。

### 3.4 三个必须代码化的算子

1. `swing.py`
   - 默认 S-A：左右 2 根枢轴、结构腿至少 1.2 ATR、跨度 5-120 根、新极值至少 0.1 ATR。
   - 高低枢轴交替，同类连续取更极端者；prev/cur 之间不得跨越更极端点。
   - S-B（平台左右 2 根局部摆点）仅作消融对照。
2. `divergence.py`
   - 同时实现 A47 与 B_hist；默认暂用 B_hist，但在签认完成前不能定稿。
   - A47 使用两个不同完整同色 MACD 段的 DIF/DEA、峰值、面积，至少两项减弱。
   - B_hist 允许同段，使用单柱 DIF/HIST 通道；不能把 GDL 研究分冒称为 quality2/3 或交易许可。
3. `h1_state.py`
   - 默认 4×M15 聚合，参数 `n=12/strong_atr=0.6/mono_ratio=0.75`。
   - 同一聚合 H1 bar 内状态锁定；只在 H1 收盘后重判。
   - veto 与 `strong_atr` 必须是独立消融开关。

## 4. 入场、价位与风险

- 顺序：方向 → M15 动能闸门 → M5/M1 证据窗口 → A/B/C/D → 证据唯一使用 → 冷却 → 价位 → G1-G7。
- 路径 A/B/C 需要原始引擎源码才能 1:1 移植。
- 路径 D 第一版带独立开关：H1 同向 strong、M15 slope 同向且无反向已确认背驰、闸门打开；最近 6 根 M5 的背驰/穿均线/吞没任一；M1 不得明确反向强势。
- 期货默认关闭 M1 确认层，作为消融项保留。
- 止损：结构锚点外扩 `0.6 ATR` 且至少 2 tick；不足 `1.5 ATR` 放宽到下限；默认上限 `6 ATR`，11.5 ATR 只作对照。
- 止盈：固定 2R。
- 手数：`floor(min(equity*risk_pct, risk_cap_abs)/(stop_distance*multiplier))`，必须为整数手；0 手即拒绝。
- 组合：单品种通常最多 1 笔、同簇最多 2 笔、组合最多 5 笔；单品种日亏 2% 熔断，组合日亏 6%（含未平仓风险）。
- 第一阶段不实现 MT5 机械补进 C10，不自动换掉持仓合约。

## 5. 掘金示例代码的使用边界

可复用：

- `fut_get_continuous_contracts` 获取交易日主力映射。
- 夜盘用下一交易日映射主力合约的思路。
- `subscribe(..., count=...)` 滑窗、`context.data(...)`、`on_bar`、`on_order_status` 回调形态。
- 持仓合约与当前主力的核对思路。

不可直接复用或必须整改：

- 示例是双均线反转策略，不包含本项目的多周期事实、状态机、风险与证据审计。
- `except:` 静默兜底会掩盖主力映射/数据错误；生产代码必须记录并失败关闭。
- 平仓成交后无条件反向开仓会绕过本项目的趋势两票确认、风险预算和订单幂等。
- 默认市价下单、固定 1 手，没有合约乘数、tick、保证金、涨跌停、平今成本、订单去重和滑点保护。
- 非主力持仓被直接平仓不等于换月；本项目默认原合约继续按原止损止盈管理，是否换月应由 `rollover_policy` 决定。
- `get_position()` 未显式账户、`order_volume()` 未显式账户，不适合多账户环境。
- 示例以自然时间调度 21:00/09:00，不能覆盖所有品种夜盘开市、节假日和交易日归属。
- 未处理部分成交、撤单、拒单、未知提交结果、重启恢复和重复回调。

## 6. 预注册门槛

- 开发集：2023-01 至 2024-12。
- 验证集：2025-01 至 2026-10，只允许正式查看一次。
- 趋势层：方向一致率 >=60%；>=2 ATR 趋势段方向覆盖率 >=70%；震荡段切换 <=1 次/日/品种；正确转向延迟中位数 <=4 根 M15。
- 收益指标仅在全池已平仓 >=300 笔后解释；单品种 <30 笔只看结构指标。
- 开发集：扣费盈利因子 >=1.3、胜率 >=40%、最大回撤 <=15%、路径 D 在震荡段触发占比 <=20%。
- 验证集：盈利因子 >=1.15，且路径贡献排序与开发集同号。
- 未过门槛不得进入自动下单；达开发集未达验证集，只允许一次改一个变量并重新预注册。
