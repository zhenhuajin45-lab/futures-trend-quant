## 连亏冷却的固定定义

- 只计 `STRATEGY` 且开平累计成交均为 1 手、账户确认该仓已平、无相关活动意图的完整闭环。以开仓意图 ID 去重，平仓意图必须绑定开仓 ID。
- 使用开平两侧成交报告中的平台模拟扣费，负数计亏损，正数清零连亏，零保留连亏。费用、数量、身份或完成时钟不全时保持待对账，不把 UNKNOWN 当 0。
- 第 3 笔及其后的每笔连续亏损，至少冷却 60 个自然分钟。第 5 笔起另禁止该交易日剩余新开，下一交易日仍须经过正常交易小节、周末/长假禁开和全部风险检查。
- 迟到的完成证据不会把冷却缩短成已经过期；乱序旧闭环需要顺序对账，不静默重算。
- 冷却和账本持久化；重复回报、重启不重复计数。冷却期间继续正常止损、止盈、技术退出和截止清仓，不新增强制砍仓规则。
- 当日基数和风险高点沿用当前状态，不改为月初基数，不引入用户建议中的 2% 日损或 15% 账户熔断。
