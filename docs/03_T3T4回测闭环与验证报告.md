# T3/T4 回测闭环与验证报告

日期：2026-11-03

## 结论

策略已达到“可在本机掘金客户端执行回测”的工程目标。真实 SDK 链路为：

`on_bar(闭合 M15) → 三频事实 → 趋势状态机 → Path D → 账户/组合风控 →
结构止损与仓位 → order_volume → on_order_status → M1 止损/止盈 → 平仓回报`。

这不是原 XAUUSD 1.0 的逐字节复刻。原始 `m5m1-combo-v1`、
`structure-facts` 与 31 个黄金用例未提供；当前版本是用户确认后的规格重构版，
只启用了附件中能够确定实现的 Path D。

## 已落地规则

- M15：EMA34、ATR14、MACD 12/26/9、12 根归一化斜率。
- H1：按交易时段固定锚点，将四根 M15 聚合；滚动窗口左端变化不会改变既有 H1 分组。
- 趋势：建立和离开均需要两根闭合 M15 确认，保留 H1 veto。
- Path D：H1 同向 strong、M15 同向斜率、无反向确认背驰、最近 6 根 M5
  出现 EMA34 穿越或吞没、M1 无明确强反向。
- 止损：结构锚点外 0.6 ATR，至少 1.5 ATR 与 2 tick；超过 6 ATR 拒单。
- 止盈：固定 2R；同一根 M1 同时触及止损和止盈时，保守地先按止损。
- 仓位：权益 1% 风险预算，受可用保证金 80% 上限约束；额外计入
  10 bps 且至少 3 tick 的成交/跳空缓冲。
- 组合：单品种 1、单集群 2、全组合 5；品种日损 2%、组合日损 6%。
- 换月：主力变化时不自动移仓；旧持仓合约继续订阅直至平仓。

## 订单安全边界

最终订单门控必须同时满足：

1. 掘金运行模式为 `MODE_BACKTEST`；
2. `execution.mode == "backtest"`；
3. `backtest_orders_enabled == true`；
4. `execute_enabled == false`。

因此当前代码不能向模拟盘或实盘发单。用户提供的模拟账户 ID 未写入仓库、配置或日志。
