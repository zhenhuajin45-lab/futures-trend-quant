# M1 时段关系资料与机制卡

**选择：仅作为本批可检验性预检的唯一资料方向，未授予开发回测预算。** 范围预先限定豆粕 `DCE.M`，因为它是原论文四类标的与用户原 12 品种的唯一交集；没有按旧收益挑选 PVC 或其他品种。

一手依据为 Jin、Kearney、Li、Yang 的作者工作论文 [Intraday Time-series Momentum Evidence from China](https://mpra.ub.uni-muenchen.de/97134/1/MPRA_paper_97134.pdf)，2019 年版本第 7、9、20–21 页。作者以首半小时方向解释尾半小时方向，并提出流动性供给和信息交易时点的机制解释。其样本截至 2013 年、按日盘定义，交易策略比较未扣交易成本；原合约选择也不能直接当成当时已知映射。以上只是本提案的来源，不证明当前条件有效。

## 一条可证伪的适配提案

| 要素 | 本批固定的预检定义 |
|---|---|
| 事前可观察输入 | 同一实际合约日盘 09:00 开盘至 09:30 收盘的方向，含 30 根完整 M1；14:30 决策时最近已闭合 M1 只用于确定当时的风险距离。零方向、缺分钟及无合法映射分别留分母 |
| 方向性理由 | 假设早盘信息与日末流动性调整之间仍存在方向延续；当前夜盘制度和时隔多年可能使它失效，不能将论文的相关性写成本项目盈利 |
| 兑现窗口 | 新适配假设：14:30 后严格等待下一合法 M1 开盘的名义时间，正常日盘为 14:31，固定 14:55 到期。零额外跨分钟延迟下最多 24 个可交易分钟。实际接收与传输延迟未知，24 分钟不是实测可成交期限 |
| 与原文差异 | 原文尾半小时至 15:00；本提案主动采用每日 14:55 固定窗口到期，兼容收盘前操作缓冲。它不是旧 D+1 规则要求所有新仓每天强平，也不是原文原样复现；该适配仍须在新协议确认 |
| 风险锚与 2R | 方向对应的早盘 30 分钟逆向极值外加 1 tick；以 14:30 已知参考价校验有向距离 R0。无效距离不填零。2R 仅为以后拟用目标，本批不计算可达率 |
| 退出与失效 | 仅结构止损、目标和固定窗口到期；不增加“几分钟不涨就退出”。新闻、早盘噪声、风险锚过远、延迟和点差均可能使其失效，目前不能提前识别哪次一定失败 |
| 唯一主对照 | 同实际合约、同日、同预定时段，用 `SHA256(20261105|合约|交易日)` 决定一个安慰剂方向；两方向都用同一方向条件风险锚公式和预算。不是挑多次随机路径的赢家。是否有共同有效风险距离另列 |
| 待开发主指标 | 候选相对安慰剂的平均每笔模型净 R 增量；应先区分信号参考优势与下一可成交价格之后的优势，再做完整账户。用户本批明确不设 delta_min，只看容量敏感性 |

案例记录：目前没有团队提供的、带当时记录且可独立复述的支持/失败交易例子，记 `UNVERIFIED`。本批抽取的旧原件例子仅核对截止前输入、方向和风险算术，不看未来结局，不能当成成功交易案例。

## 数据和权限

已有豆粕实际合约 M1 可做**旧窗字段、时钟和容量工程检查**，不计算新收益；不复用 631 笔旧成交作为新机会队列。新开发窗和独立窗均未合格，历史映射首次可知时刻与接收时钟未知，候选时点的开平盘口、同期费用和传输延迟也未核验。

这张卡的作用是把下一笔数据决策说明白。它不重新激活 S0/A/B/C/D，不以增加测试或更换参数表示机制已经进展，也不自动分配数据采购预算。
