一手来源为作者仓库 [cnfutures 固定版本](https://github.com/BobbyShiyi/cnfutures/tree/8a45a117008f1495070ef6e0b56bd321c809d761)。作者定义五档挂单量失衡加权值，并在标准化时排除当前段；报告样本外预测力，同时报告下一报价主动成交、扣点差和费用后为负。原五档数据为私有授权数据；固定提交树中未见 README 所述 `backtest.py`。本批经 GitHub API 核对树和 README blob，不将作者结果称为已独立复现。

| 必需项 | 本机核验与边界 |
|---|---|
| 连续五档价格和数量 | 38 个源 SHA 可核的旧历史入场小包共 372 条 tick，观测到的 `quotes` 数组均为一档；不是连续五档来源 |
| 信号首次可得时刻 | 小包有 `created_at`，无本机 `received_at`；历史下载时刻不能回填当年接收时刻 |
| 主动订单流 | 未发现足以构造主动买卖方向的已核验原件；静态挂单量失衡和主动成交失衡分开，不互换 |
| 可成交进入和退出 | 这些是旧入场附近最多 5 秒样例，不覆盖本提案的连续触发、退出和时延。显示挂量不保证成交 |
| 可检验的方向差异 | 尚未提出有来源、能解释为何本项目可跨越作者主动成交负结果的实质差异，记 `UNVERIFIED` |

若未来另作数据决策，最低字段应含实际合约、交易小节、五档双侧价格与数量、交易所事件时钟、本机接收时钟、序列或更新标识及断线缺口、适用费用；如要研究主动流还需相应成交方向证据。报价队列与挂单成交另需证据。本批没有向该作者、供应商或券商索取新数据、授权或报价。
