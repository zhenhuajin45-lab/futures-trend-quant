# 历史趋势与2R机会研究登记

基线316d0ed，样本2026-05-07至11-02，12品种，属于已观察的探索样本。S0采用已闭合H1修正版。EMA34只作趋势参照，历史离场A只作已登记的时机对照。v5采证和冻结90日目录独立运行。

主研究在未复权的同一实际合约内逐根推进。用前一已完成交易日主力映射选择当日研究合约，明确假设历史映射可用，真实发布时间为UNKNOWN。每个实际合约先独立预热并计算指标及状态，主力切换不会把事后价差传入早盘。原归档序列只作旧证据复算，补片与主研究分别保留身份。EG和AG补片须核对共有行一致，再并入独立视图。数据不足的行和品种保留分母与原因。

信号按品种、实际合约、方向、路径、证据ID去重。主参考价为信号后第一根合法同合约M1开盘。结构止损调用原build_stop_plan，固定该止损后按参考价重算R和2R目标。观察8/48根M15的同合约M1顺序，先看每分钟开盘，再看高低，保留双触、无触及、删失和开盘已穿止损。未来缺口从缺失点截尾，已确定首触另列。跨休市、换月和流动性未知分别标记。

对照在同合约、同方向授权、同交易日同小节、同动能状态中选择未接受候选的M15。ATR/价格比例差不超过20%，依授权持续根数差、时间差、较早时刻排序，无放回且不读取未来标签。对照采用同R/ATR尺度。匹配率低于70%或主配对差区间跨零，结论不足以确认增量。固定5/10交易日块、10,000次、种子20261104。子组少于30机会不作路线选择。

先验证CF、EG、AU工程切片，再运行全部可用品种。至少8例手算及反例验证。有真实证据表明已授权方向下M5条件提前齐备且T2支持时，才试一次M5评估时钟。否则给出停止该试验的证据。费率、账户账本与收益不进入本轮。机器口径见tools/historical_strategy/registration.json。
