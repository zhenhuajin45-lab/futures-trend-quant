## 4 架构与开发位置

新增模块放在 `futures_trend_quant/observation/price_action/`，与被冻结核心分离：

```text
models.py          公共不可变模型、状态枚举、原因码、schema校验
structure.py       复用已确认枢轴，构建M15/M5价格结构
zones.py           关键区域、成熟区间、触碰与角色转换
patterns.py        实体、影线、收盘位置和位置关联
breakout.py        越界、接受、收回、回踩的事件状态机
room.py            反向障碍、空间、费用和净空间R
invalidation.py    与入场假设绑定的失效事实，仅影子
pipeline.py        统一as-of快照与逐候选影子评估
state.py           独立持久化、重启恢复与去重
```

集成点：FiveRunner仅向独立、有界的观察队列提供闭合事实；观察工作不得同步阻塞账户/风险/退出定时器。观察器不持有GM_TOKEN或账户控制器，不导入原生下单适配器。影子队列满、观察错误或历史缺失，标记观察不可用及缺口，不能默默丢弃后仍显示健康，也不能通过修改原委托权限补偿。

新增 `tools/price_action_shadow_replay.py`、`tools/price_action_shadow_report.py` 和相应tests。回放必须使用冻结原件及真实可知时间，不重新向供应商取今天历史覆盖原件。

独立配置建议 `config/price_action_shadow.local.json`；独立状态 `state/paper_observation_five/price_action_shadow/`；独立证据 `evidence/paper_observation_five/price_action_shadow/`。影子配置单独校验和入manifest，不改变现有执行配置哈希及S0检查点。新增源码仍进入完整main发布指纹。影子层故障在SHADOW下不触碰engine.pause_entries或报单；未来ENFORCE模式的证据不完整必须阻断新开，退出监督继续。

## 5 数据契约与可知时刻

每个事实/候选至少携带以下公共字段：

| 字段 | 语义 |
|---|---|
| schema_version / policy_version / parameters_sha256 | 结构、位置、空间及参数身份 |
| symbol / csymbol / frequency / trading_day / session_id | 实际合约与交易日历身份，禁止跨主力拼接结构 |
| source_bar_ids / source_prefix_sha256 | 原始闭合K线集合及本机前缀证据 |
| occurred_at / confirmed_at | 极值发生与规则确认时刻，分开保存 |
| first_received_at / computed_at / known_at | 实际入库、计算与首次可用时间；缺值UNKNOWN |
| asof_at / watermark / completeness | 查询时点、连续覆盖及完整性 |
| event_id / episode_id / candidate_evidence_id | 稳定事件、结构过程和原交易候选关联 |
| status / reason_codes / terminal_at | 当前状态、第一拦截、后续事实和终态 |

`known_at`必须同时满足规则所需数据已经闭合、确认数据已经收到及计算结果已存在；有任何必要接收时钟缺失，不能伪造精确可用时间。历史回放必须遵守当时接收顺序，不能把今天才确认的枢轴放回极值那根K线使用。

同价多事件按稳定bar_id与确认时间排序；等高等低用tick离散值表达。窗口滚动不能删除已产生的事件身份或让已确认结构静默变形。修订、缺口、换月和小节切换都要有显式规则与失效记录。

## 6 结构状态的初版规则

先复用现有S_A确认枢轴参数和不可变bar_id，分别输出M15与M5结构，避免重新搜索另一套最优枢轴参数。只使用 `confirmed_at <= asof_at` 且数据已经收到的枢轴。

比较最近两个有效高点和最近两个有效低点：

- 高点、低点均抬高：UP；均降低：DOWN。
- 高低点方向交错：TRANSITION；不足两对、缺口或确认不完整：UNKNOWN。
- 等高/等低单独标记，不强行归入上涨/下跌；初版按实际tick离散比较，不额外优化价格容差。
- RANGE必须由独立区间证据成立；背景none或结构TRANSITION都不自动等于震荡。

保存 `protected_pivot_id/price`。上涨结构的保护低点被闭合价格有效破坏，先记UP_DAMAGED，不立即反向做空；后续确认更低高点/更低低点才形成独立DOWN事实。反向逻辑对称。影线触及、影线越界和收盘破坏分别记录，不能混为同一事件。

新增输出字段：`structure_state`、`high_relation`、`low_relation`、`protected_pivot`、`damage_event`、`next_confirmation_required`。保留现有 `production_m15_background`，不能把新结构事实直接覆盖原趋势授权。

## 7 关键区域与区间位置

初版区域来源限于：已确认M15枢轴、上一完整交易日高低点、已形成的M5短箱体。前一交易日按真实交易日历计算，不能以自然日零点切割夜盘。更长周期结构、成交量分布等不混入首版。

每个区域保存 `zone_id/type/lower/upper/source_ids/born_at/known_at/touch_events/role/status/invalidated_at`。已知区域可以合并，但合并产生新版本，不能回改历史区域边界。

研究初值：区域半宽 `max(2*tick, 0.1*ATR_M15)`，仅作为固定影子工程起点，不声称最优，也不是止损参数。ATR在区域出生时冻结，未来波动变化不改写旧区域。触碰按独立离开后再进入的过程计数，连续多根黏在区域内不能虚增强度。

区间分两类：沿用C路径4根M5窄幅箱体用于解释原候选；另输出成熟价格区间，初版在最近20根闭合M15中要求上下边界各有至少两个已确认枢轴触点，边界聚类和事件间隔使用冻结配置。不能将当前突破柱纳入形成箱体的样本。

区间位置 `position=(entry-box_low)/(box_high-box_low)`；分母无效则UNKNOWN。研究初值0.35—0.65标记MIDDLE，其余按上下边缘及区间外分别标记。MIDDLE首版只作标签，不直接拦单；边界偏离、扩张或趋势恢复时显式结束区间。

新增输出：`nearest_support`、`nearest_resistance`、`location_class`、`distance_to_zone_ticks/atr`、`zone_role_change`。区域质量先展示触碰/拒绝/破坏事实，不用未经验证的加权总分替代证据。

## 8 形态质量和突破过程

现有Pin Bar/吞没定义保留，新增 `body_ratio`、`upper/lower_wick_ratio`、`close_location`、`range_atr`、`preceding_regime` 和 `related_zone_id`。零实体、零振幅、停牌/无成交归一化分钟、异常tick和不同合约必须有明确结果，不能因除零或极小实体被自动评为优质。

Inside Bar定义为全振幅被母K线包含；母K身份持久化，多层内包共享母K，不重复生成独立买卖信号。内包只表示收缩，方向仍需后续突破/确认。

突破状态机：

```text
KNOWN_ZONE -> PROBE_OUTSIDE -> CLOSE_ACCEPTED -> RETEST_PENDING -> RETEST_HELD
                       |                |
                       +-> CLOSED_BACK  +-> FAILED_ACCEPTANCE
```

区分同根影线越界后收回、收盘突破后再收回、突破后的首次回踩守住。假突破必须引用事先已知边界，并在收回/反向确认已经发生后才成为事件；不能事后把一次失败越界重标为当时可交易的Fakey。

初版收盘接受按超过区域外边界至少1tick记录，持续接受根数作为事实输出，不立刻做参数优化。每个越界过程拥有一个episode，遇到缺口/换月/失效/重复事件正确结束。仅拦截失败突破与直接生成反向交易分成两个实验；首版不新增生产反向路径。

## 9 失效与实际盈利空间

各路径先映射交易假设：A为转强/转弱证据组合，B为有序回撤结束，C为横盘后延续，D为强背景下触发。以实际选中路径和原proof为准，不能用新标签重写原入场事实。

影子失效观察分别引用回撤保护枢轴、突破边界、拒绝区域或假突破极值。保存“价格触及”“闭合破坏”“结构重新确认”为不同事实；首版不改变现有止损、2R目标、平今平昨、D+1和截止义务。

对真实候选同时保存两个结果：

1. 原计划：原结构止损、ATR、2R目标、单手风险和固定时钟。
2. 影子空间：前方第一个事先已知的反向区域、到区域近端的距离、与2R目标的关系和成本后空间。

做多取上方最近阻力区域的近端，做空取下方最近支撑区域的近端；已处在反向区域内则可用空间为0。未知费用、报价或区域覆盖不足时输出UNKNOWN；没有发现障碍只输出NO_OBSTACLE_OBSERVED，不自动赋予无限空间或PASS。

统一以一手金额计量：风险 `R_gross=abs(entry-stop)*multiplier`；障碍前毛空间 `W_gross=directional_distance_to_zone*multiplier`；`RR_space_net=(W_gross-C_win)/(R_gross+C_loss)`。费用按实际合约/生效日/开平侧，滑点为显式研究假设。若entry已采用真实可执行报价或委托计划，不能再把已经包含的入场价差重复计费。

费用或成交价未知时，不展示伪精确净R。首版影子参考阈值为2R并同时保留连续值；不得通过缩紧止损、延长目标、重置期限或假设穿越障碍来凑比值。目标调整、分批退出和追踪退出另设实验，不能与位置过滤混在同一对照组。

## 10 候选选择与原生出口的未来接入

本轮SHADOW流程：闭合事实 -> 原ABCD形成/资格/竞争 -> 原实际执行链，同时旁路构建PA快照并关联原candidate_evidence_id。即使原候选被停开拦截，也可保存影子结果，但标明没有真实成交和下游NOT_EVALUATED。

未来S4接入时：先按每条路径分别核验结构、位置和空间，再在合格路径中执行既有竞争规则，避免新增门槛只评选中路径而掩盖其它合格路径。不能在未知提交后借“另一条合格路径”重发。

原生新开出口必须核验同一PA策略/参数/合约/run_id/候选身份、快照可知时刻、原截止及最终报价变化。最终报价导致空间不足时记录当前本地拒绝，不续期、不修改冻结锚点，不影响合法退出。需要启用时另行注册新入场版本、配置身份和迁移回执，禁止复用旧版本名称承载新硬门槛。

## 11 参数与研究纪律

以上2tick/0.1ATR、20根窗口、中部0.35—0.65、1tick接受及2R参考均为首版待验证的研究初值。实现前写入独立配置和参数指纹，登记试验次数；数据类型、因果和状态机测试不用于挑选最优收益参数。

按品种和连续时间切分训练/验证/留出，使用前推而非随机打乱。标签涉及持仓路径时，隔离重叠样本并按实际持仓期限留出间隔。自然无信号和被原风控拦截的日子保留，不只挑成交/盈利时段。

首轮统计准入目标预登记为至少20个独立交易日、200个原策略技术候选，至少覆盖三品种，并披露未覆盖品种/路径。该数量只是研究覆盖下限，不保证统计充分或收益成立。稀疏路径不凑样本、不生成测试单，样本不足继续SHADOW；一个交易日或443项软件测试不能替代交易优势验证。

主指标：扣费后期望的估计与不确定区间、最大回撤、收益集中度、持仓/信号延迟和跨时段稳定性；辅助指标：胜率、盈亏比、MAE/MFE、被过滤盈利/亏损机会和相关品种同时占仓。逐项对照原策略、仅结构、仅位置、仅空间，再评估组合；记录所有试验，拒绝只报告最好版本。

原策略没有实际报单时，新版本的收益结果只能是明确标识的离线假设，必须有报价、成交可得性和延迟模型；不能把触价当保证成交。缺历史盘口的样本不宣称精确可交易收益。组合2仓是数量上限，不代表油脂相关风险已自动受控，首版只补相关暴露归因。
